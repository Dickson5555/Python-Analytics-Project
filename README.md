## Getting Started

Clone the repository:

```bash
git clone https://github.com/Dickson5555/Python-Analytics-Project.git
cd Python-Analytics-Project
```

Create and activate a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Install the dependencies for an individual project from its `requirements.txt` file. For example:

```bash
cd Haul_Prediction
pip install -r requirements.txt
streamlit run main.py
```

For the geological engineering application:

```bash
cd "AI in Geological engineering"
pip install -r requirements.txt
streamlit run Geo.py
```
